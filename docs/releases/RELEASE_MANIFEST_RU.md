# Состав релиза CoolSnesh Downloads v1.0.0

Рабочий исходный снимок до последующих экспериментов со сбросом Git-истории. Включены все основные функции, подтверждённые к моменту, когда пользователь сообщил, что приложение работает как надо:

- UI Avalonia/XAML в тёмной теме, исправленный поиск, иконка аниме-девочки, версия и кнопка автообновления в боковой панели.
- Каталог: «Для России», «Программы», «Браузеры», «Windows», «Игровые лаунчеры».
- Browser resolver для Tor Browser и LibreWolf, источник Ventoy GitHub, ArtCraft Launcher, 7-Zip/WinRAR, Windows ISO и системные runtimes.
- Встроенные SVG/PNG-иконки и системная иконка EXE/окна.
- Версии установленных приложений, нормализация сравнений, детект Steam и Flowseal, ручные пути Flowseal только в настройках.
- Тихое обновление поддерживаемых установщиков, временное хранение установщиков, очистка и запрос прав UAC при необходимости.
- Безопасное обновление Zapret с защитой пользовательских списков и отдельное обновление TG WS Proxy.
- Настройки прокси: HTTP/HTTPS/SOCKS4/SOCKS5, переключатель, парсер `ip:port:login:password`, сохранение пароля через DPAPI и тест соединения.
- Самообновление через GitHub Releases: отображение новой версии, проверка имени EXE/исторических имён, проверка SHA-256, staging и отдельный помощник замены с резервной копией.
- Юнит-тесты сравнения версий, каталога и поведения updater.
- `build.yml` для проверки/сборки и `release.yml` для публикации прямого EXE, ZIP и SHA-256.

Версия в `CoolSnesh.Avalonia.csproj` установлена в `1.0.0`. Внутренние имя проекта/assembly/namespace оставлены `CoolSnesh.Avalonia`, а публикуемое имя EXE — `CoolSnesh Downloads.exe`.

## Ограничение проверки

Архив проверен статически (файлы проекта, XAML/XML, YAML workflow, каталог и наличие ресурсов). Полную компиляцию/запуск тестов здесь подтвердить нельзя, так как в среде подготовки не установлен .NET SDK. Первый запуск GitHub Actions должен подтвердить компиляцию на `windows-latest`.
