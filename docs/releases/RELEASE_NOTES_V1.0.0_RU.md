# CoolSnesh Downloads v1.0.0 — состав релиза

Это снимок рабочей версии приложения на момент подтверждения работы основных функций. Проект сохраняет внутреннее имя `CoolSnesh.Avalonia`, а пользовательское имя приложения и релизный EXE — `CoolSnesh Downloads.exe`.

## Возможности

- Тёмный интерфейс в стиле UniGetUI: поиск, каталог, список загрузок, история, настройки и уведомления.
- Категории «Для России», «Программы», «Браузеры», «Windows» и «Игровые лаунчеры».
- Оригинальная иконка приложения с аниме-девочкой; SVG/PNG-иконки браузеров и программ.
- Установка и обновление выбранных приложений, контекстное меню по правому клику, тихие параметры там, где они заданы, UAC при необходимости и очистка временных установщиков.
- Сохранение версий установленных программ, нормализация версий, обнаружение Steam и Flowseal; ручные пути Flowseal — только в настройках.
- Обновление Zapret с проверками состояния стратегии и сохранением пользовательских списков; отдельная безопасная замена TG WS Proxy.
- Прокси HTTP/HTTPS/SOCKS4/SOCKS5, вставка `ip:port:login:password`, переключатель прокси, сохранение пароля через Windows DPAPI и тест соединения.
- Браузеры: Chrome, Firefox, Яндекс Браузер, Opera, Opera GX, Edge, Brave, Vivaldi, Tor Browser и LibreWolf; для Tor показывается уведомление о VPN/прокси.
- Вкладка Windows: ISO Windows 11 26H2 и Windows 10 22H2, Ventoy, Rufus, Visual C++ Redistributable x86/x64, .NET Framework 3.5/4.8/4.8.1, .NET Desktop Runtime и NVIDIA App.
- Архиваторы 7-Zip и WinRAR, ArtCraft Launcher.
- Сравнение версий в переиспользуемом сервисе `VersionComparison`, `VersionResolver` для источников версий и тестовый проект xUnit.
- Самообновление приложения через GitHub Releases: уведомление в боковой панели, проверка EXE и SHA-256, staging, отдельный помощник замены и попытка отката.
- GitHub Actions для тестов/сборки и публикации релизов по тегу `vMAJOR.MINOR.PATCH` или ручного переиздания существующего тега.

## Что публикуется

Успешный workflow `release.yml` создаёт четыре Assets:

- `CoolSnesh Downloads.exe` — автономный Windows x64 EXE;
- `CoolSneshDownloads-win-x64.exe.sha256` — SHA-256 EXE;
- `CoolSneshDownloads-win-x64.zip` — ZIP опубликованной папки;
- `CoolSneshDownloads-win-x64.zip.sha256` — SHA-256 ZIP.

Публикация берёт версию из тега. Для первой официальной версии используйте тег `v1.0.0`.

## Сборка локально

Требуется .NET 10 SDK и Windows 10/11. Из корня проекта:

```powershell
dotnet restore .\CoolSnesh.Avalonia.sln
dotnet test .\CoolSnesh.Avalonia.sln -c Release
dotnet build .\CoolSnesh.Avalonia.csproj -c Release
dotnet publish .\CoolSnesh.Avalonia.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true
```

При подготовке этого архива .NET SDK в среде сборки не был доступен, поэтому эта сборка является полным исходным релизным пакетом, а не заранее скомпилированным EXE. GitHub Actions выполнит компиляцию после загрузки исходников.

## Исправление отображения версии

- Версия приложения теперь отображается с сохранением всех основных сегментов: `1.0.0`, а не `1`.
- Метаданные сборки после `+` не показываются пользователю; служебная четвёртая ревизия `.0` у `AssemblyVersion` убирается.
- Добавлены тесты форматирования версии приложения для обычной версии, версии с build metadata, четырёх сегментов и prerelease.

## Исправление отображения версии приложения

- В пользовательском интерфейсе сохраняются все основные компоненты версии: `1.0.0` отображается как `1.0.0`, а не `1`.
- Метаданные сборки (`+...`) не показываются; четвёртая служебная ревизия `.0` из `AssemblyVersion` отбрасывается.
- Версия последнего GitHub-релиза в окне обновления также отображается с исходными сегментами.
- Добавлены тесты форматирования версии и отображения релиза `v1.0.0`.
