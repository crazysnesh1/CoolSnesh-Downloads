# Логические блоки изменений

Архив содержит шесть логических блоков вместо отдельных Git-коммитов: исходная папка не была настроена как Git-репозиторий.

## 1. Каталог и иконка
- Категория `Сервисы` переименована в `Для России`.
- В колонке сайта оставлена только кнопка со стрелкой.
- Исходный `5ZBX16UehAA (1).ico` используется окном и как иконка EXE через свойство `ApplicationIcon`.

## 2. Определение установленной версии
- Поиск uninstall-записей Windows в HKCU/HKLM и 32-/64-битных представлениях.
- Чтение `ProductVersion`/`FileVersion` выбранного EXE и известных EXE пакета.
- Для Zapret читается `LOCAL_VERSION` из `service.bat` либо `.service/version.txt`.
- Для приложений Flowseal добавлен ограниченный поиск обычных папок и версий из локальных манифестов.
- Добавлены действия ручного выбора EXE и папки, путь сохраняется в `settings.json`.

## 3. Тихие и пакетные обновления
- Глобальный переключатель `Тихое обновление` в каталоге и настройках.
- Установка выбранных пакетов выполняется по одному, с журналированием и обработкой `0`, `3010` и других кодов.
- Для неизвестных инсталляторов параметры не угадываются — установщик не запускается.
- Flowseal TG WS Proxy обновляется отдельной процедурой замены portable EXE: процесс проверяется, новый файл подготавливается отдельно, исходник сохраняется в резервной копии; при запущенном EXE обновление останавливается без замены.
- Отмена текущей тихой установки завершает её процессное дерево и предупреждает о возможной необходимости восстановления.

## 4. Защищённый сценарий обновления Zapret
- Проверка корня, структуры архива и небезопасных путей.
- Сохранение и побайтная проверка пользовательских `*-user.*` списков перед остановкой.
- Остановка и повторный запуск службы `zapret` с сохранёнными аргументами, если это однозначно подтверждено реестром и путём службы.
- Отказ обновлять файлы при неоднозначно работающем отдельном BAT/`winws.exe`.
- Резервная копия старой версии сохраняется; предусмотрена попытка отката, если служба не запускается.

## 5. Прокси и обратная совместимость
- HTTP/HTTPS/SOCKS4/SOCKS5 для версии, релизов и загрузок.
- Опциональная авторизация; пароль скрыт в UI и зашифрован Windows DPAPI в конфиге.
- Общие сетевые клиенты пересоздаются после сохранения настроек.
- Конфиг имеет номер схемы, отсутствующие поля дополняются defaults, предусмотрен `.bak`.

## 6. Документация и ограничения
- Добавлено описание сборки, тестирования, стратегии обновления Zapret и списка тихих параметров.
- Отмечено, какие источники не позволяют достоверно сравнить версии до запуска установки.
- Отмечено отсутствие локализационной инфраструктуры и невозможность проверить реальную сборку в среде подготовки без .NET SDK.

## Исправление сборки после первого запуска

- Заменён несуществующий в Avalonia `PasswordBox` на `TextBox` с `PasswordChar = '●'`.
- Чтение пароля теперь использует `TextBox.Text`; визуальная маскировка символов сохранена.
- Устаревшие свойства `Watermark` заменены на `PlaceholderText` для совместимости с Avalonia 12.


## Обновление интерфейса браузеров и иконок

- Добавлена вкладка «Браузеры» с 10 распространёнными браузерами и официальными ссылками на загрузку.
- Добавлена загрузка и дисковый кэш favicon официальных страниц; для пакетов без подтверждённого значка остаётся буквенный fallback.
- Добавлены отдельные действия «Скачать выбранные» и «Обновить выбранные», а также контекстное меню строки.
- Добавлены всплывающие описания через значок информации перед иконкой приложения.
- Для Opera и Opera GX добавлено чтение версии из официальных каталогов выпусков; добавлены тесты парсеров Tor Browser, Vivaldi и Opera.

## Дополнение: вкладка Windows, архиваторы и ArtCraft Launcher

- Добавлена категория «Windows» с Windows 11 26H2 и Windows 10 22H2, а также Ventoy и Rufus.
- ISO сохраняются по удобным именам `Windows11_26H2.iso` и `Windows10_22H2.iso`. Ссылки Google Drive обрабатываются отдельно, включая типичную страницу подтверждения для крупных файлов. Для этих файлов нужно разрешить доступ «Все, у кого есть ссылка».
- Подсказки ISO содержат дату 17.10.2026 из предоставленных сведений и оговорку, что происхождение файла следует перепроверить контрольной суммой SHA-256. Само содержимое пользовательских Drive-файлов независимо не проверено.
- В каталог «Программы» добавлены 7-Zip, WinRAR и ArtCraft Launcher. Для 7-Zip, WinRAR, Ventoy и Rufus версии и установщики читаются с официальных страниц/релизов.
- ISO, Ventoy и Rufus помечены как доступные только для скачивания: каталог не пытается устанавливать ISO или запускать портативные инструменты как обычные установщики. Контекстное действие обновления для них отключено.
- Иконки увеличены до 40×40 px, цветная фоновая плитка вокруг значков убрана; резервная текстовая метка показывается без рамки.
