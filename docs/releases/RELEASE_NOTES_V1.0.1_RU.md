# CoolSnesh Downloads v1.0.1

## Каталог VPN и прокси

- Добавлена отдельная категория **«VPN и Прокси»**.
- В неё перенесены Proxifier, v2rayTun и Happ.
- Добавлен Incy для Windows x64. Версия и ссылка на установщик считываются из официального `RELEASE.json` проекта INCY, поэтому каталог использует версию Desktop и не путает её с мобильными релизами.
- Добавлены тесты категории, разбора манифеста Incy и разрешённых ссылок на установщик.

## Проверка автообновления

Для реальной проверки нужен опубликованный GitHub Release с тегом `v1.0.1`. Сборка версии `1.0.1` сама по себе не создаёт релиз и не включает его в механизм автообновления.

После добавления этих изменений в репозиторий опубликуй тег:

```powershell
git tag -a v1.0.1 -m "CoolSnesh Downloads v1.0.1"
git push origin v1.0.1
```

Workflow `release.yml` запустит тесты, соберёт EXE/ZIP, вычислит SHA-256 и опубликует релиз. Затем запусти уже установленную версию `1.0.0`: она должна предложить обновление до `1.0.1`. После установки проверь, что в приложении отображается версия `1.0.1`.
