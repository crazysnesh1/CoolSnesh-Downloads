# Исправление обновления установщиками

## Что изменилось

1. **Временная папка для обновлений.** Кнопка «Обновить выбранные» больше не использует выбранную папку загрузок/рабочий стол. Каждый установщик скачивается в уникальную папку `%TEMP%\CoolSneshDownloads\Installers\<id>`.
2. **Очистка после обновления.** После успешной или неуспешной попытки установщик и пустые временные каталоги удаляются. Если процесс продолжает работать после тайм-аута и файл занят, очистка повторяется после завершения процесса. Обычная кнопка «Скачать» по-прежнему сохраняет файл в выбранную папку.
3. **Тихий WinRAR.** Для WinRAR используется `/S`; для его обновления запрашиваются права администратора, поскольку типовая установка находится в `Program Files`.
4. **Запуск с повышенными правами.** Весь CoolSnesh не запускается от администратора. Права получает только процесс установщика: для приложений, расположенных в `Program Files`, UAC вызывается заранее; для остальных сначала выполняется обычный запуск и при Windows error 740 повторяется запуск через `runas`. Отмена UAC обрабатывается отдельным статусом.
5. **Живой статус и тайм-аут.** Пока установщик работает, строка обновляется каждые две секунды. Через 20 минут программа перестаёт бесконечно ждать и показывает понятное предупреждение; процесс автоматически не убивается, чтобы не прерывать потенциально идущую установку.
6. **Логи.** Начало запуска, режим тишины/elevation, код возврата, тайм-аут и результаты очистки пишутся в лог приложения.

## Почему не включено `requireAdministrator` для самого приложения

Это вызвало бы UAC при каждом запуске каталога и повышало бы права у всех его операций, включая сеть и работу с пользовательскими файлами. Подход ближе к UniGetUI — поднимать права только для конкретной операции установки/обновления. В UniGetUI эти права определяются пакетным менеджером/метаданными установщика, а некоторые ошибки позволяют повторить операцию с повышенными правами либо в интерактивном режиме.

## Проверка

В среде подготовки не установлен .NET SDK, поэтому сборка и реальное обновление WinRAR здесь не запускались. Проверь в Windows:

```powershell
dotnet build .\CoolSnesh.Avalonia.csproj -c Release
dotnet run --project .\CoolSnesh.Avalonia.csproj
```

Затем нажми «Обновить выбранные» на WinRAR: должен появиться запрос UAC, установщик не должен попадать на рабочий стол, а после завершения временный файл должен быть удалён. В случае сбоя смотри `%AppData%\CoolSneshDownloads\logs\launcher.log` и MSI/installer-лог рядом с ним.
