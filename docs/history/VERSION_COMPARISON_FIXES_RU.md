# Исправления статусов и определения версий

Изменения сгруппированы в семь логических блоков, соответствующих запросу. Репозиторий в рабочем архиве не содержит `.git`, поэтому отдельные Git-коммиты здесь создать нельзя; этот файл фиксирует границы блоков для последующего коммита.

## 1. Ручные пути только в настройках Flowseal
- **Было:** в каталоге у каждой строки были кнопки `EXE` и `Папка`, путь также отображался под статусом.
- **Стало:** из каталога убраны поле/диалог выбора пути и текст пути. В настройках добавлен резервный выбор пути только для Flowseal (Zapret и TG WS Proxy), есть сброс ручного пути. Автодетект запускается первым; сохранённый вручную путь используется только при неудаче автоопределения.
- **Совместимость:** старые ключи `InstallationPaths` сохраняются в settings.json, но для не-Flowseal больше не используются. Существующие пути Flowseal продолжают работать как fallback; если автоопределение обнаружило файл, но не смогло прочитать версию, сервис всё равно пробует заданный в настройках путь. Отсутствующий путь очищается без исключения.

## 2. Дублирование статуса
- **Было:** при недоступной версии источника текст «актуальная версия источником не предоставляется» повторялся в status-line.
- **Стало:** этот статус показывается первой строкой через `VersionCaption`; вторая строка для установленного приложения показывает `Установлено: X`.

## 3. Разное число сегментов
- **Было:** `1.11.2` и `1.11.2.0` могли считаться разными из-за ограничений `System.Version`.
- **Стало:** `VersionComparison` нормализует числовые компоненты и считает отсутствующие конечные сегменты нулями.

## 4. Префиксы в номерах версий
- **Было:** строки с `release-`, `v`, `ver.` или `version ` могли не распознаваться.
- **Стало:** `VersionComparison.Normalize` удаляет поддерживаемые префиксы перед сравнением.

## 5. Источники актуальной версии
- **Было:** Discord и Proxifier отображались без актуальной версии, хотя Discord предоставляет манифест обновления, а Proxifier публикует версию Windows на странице загрузки.
- **Стало:** Discord использует официальный update manifest `https://updates.discord.com/distributions/app/manifests/latest?channel=stable&platform=win&arch=x64`; Proxifier парсит официальный `https://www.proxifier.com/download/` и берёт версию Windows Standard Edition (страница отдельно указывает `Version 4.14` для Windows и `Version 3.15` для Mac, поэтому парсер ограничен заголовком Standard Edition); Steam берёт номер стабильной сборки из CDN-манифеста клиента Valve `https://client-update.fastly.steamstatic.com/steam_client_win64`. GitHub-релизы продолжают проверяться через Releases API.
- **Ограничение:** для Battle.net, Epic Games Launcher, EA app и Ubisoft Connect в текущем проекте не найден подтверждённый публичный endpoint/официальная страница, отдающая номер последней версии в надёжно парсируемом виде без скачивания самого установщика. Для них сохраняется честный статус «Актуальная версия источником не предоставляется»; сравнение с неподтверждённой версией не производится.

## 6. Билд в круглых скобках
- **Было:** версия `3.3.6(591)` могла быть признана некорректной.
- **Стало:** суффикс сборки в конце версии удаляется для сравнения и отображения. При latest `4.5.4` статус — `Доступно обновление 3.3.6 → 4.5.4`.

## 7. Steam
- **Было:** детект полагался в основном на ключи Uninstall и мог не увидеть обычную установку Steam.
- **Стало:** добавлен поиск SteamPath/InstallPath в HKCU/HKLM в 32- и 64-битных представлениях реестра, типовые каталоги и активный процесс `steam.exe`. Если найдено несколько установок, предпочтение отдаётся корню, где удалось прочитать версию. Локальная версия читается сначала из `package/steam_client_win64.manifest`, затем из `steam.inf` (`ClientVersionSteam` / `ClientVersion`). Актуальный номер берётся из `steam_client_win64` на Valve CDN; числовые сегменты нормализатора используют `long`, чтобы не переполниться на длинном ID сборки.

## Тесты
Добавлен `Tests/VersionComparison.Tests` с проверками:
- `1.11.2 == 1.11.2.0 == 1.11.2.0.0`;
- `release-5.2.4 == 5.2.4`;
- `3.3.6(591) == 3.3.6` и отображение обновления Happ;
- префиксы `v`, `ver.`, `version`;
- пустые/некорректные строки возвращают отсутствие результата сравнения;
- парсинг манифестов Discord, Proxifier и Steam;
- отсутствие дублирования текста источника в status-line.

Запуск тестов на машине подготовки невозможен: в среде нет `dotnet`. Выполнить на Windows с .NET 10 SDK:

```powershell
dotnet test .\CoolSnesh.Avalonia.sln -c Release
```

В проекте нет отдельной системы локализации; новые подписи добавлены в существующем стиле строк интерфейса.
