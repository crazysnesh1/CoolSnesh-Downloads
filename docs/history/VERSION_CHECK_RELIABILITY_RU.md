# Исправление нестабильной проверки версий и сообщения Tor Browser

## Что было
- При временных сбоях HTTP/API проверка сразу завершалась ошибкой.
- Повторное нажатие «Проверить версии» создавало новые запросы ко всем источникам, что могло попадать в ограничения публичных API и снова вызывать ошибки.
- Последняя успешно полученная версия могла заменяться текстом ошибки.
- Подсказка Tor Browser рисовалась внутри горизонтального StackPanel без ограничения ширины и могла пересекать колонку версии.

## Что стало
- Проверка каждой версии повторяется до 3 раз при таймаутах, сетевых сбоях, 408/425/429/5xx, JSON-ошибках и GitHub rate-limit 403. Интервалы увеличиваются: 650, 1300 мс (и далее при дополнительных попытках).
- Последний успешный ответ кэшируется на 5 минут, чтобы повторные нажатия не создавали лишнюю нагрузку на источники.
- Если источник временно недоступен, предыдущая успешная версия остаётся видимой и появляется предупреждение «Не удалось перепроверить; показана последняя успешная версия». Если успешной версии ещё не было, отображается обычная ошибка.
- Параллельная проверка снижена с 4 до 3 одновременных запросов.
- Колонка приложения переведена на Grid с шириной текста по звёздной колонке; предупреждение Tor Browser имеет явный перенос между «VPN» и «или прокси» и больше не должно перекрывать колонку версии.

## Проверка
Добавлен тест на повтор после HTTP 503 и на использование успешного кэша при повторной проверке, а также тест на перенос строки Tor. XML-файлы проекта проверены. Полная компиляция и `dotnet test` требуют установленного .NET 10 SDK на Windows.

## Сборка автономного EXE
```powershell
dotnet restore .\CoolSnesh.Avalonia.sln
dotnet test .\CoolSnesh.Avalonia.sln -c Release
dotnet publish .\CoolSnesh.Avalonia.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true
```
