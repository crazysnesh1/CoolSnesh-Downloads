# Обновление интерфейса каталога — браузеры и иконки

## Что изменено

1. **Официальные иконки.** Для приложений с официальной веб-страницей загружается favicon сайта через endpoint favicon service; иконки кэшируются в `%AppData%\CoolSneshDownloads\Icons`. Для пакетов без подтверждённого логотипа остаётся цветной буквенный значок, а не общий логотип GitHub. TG WS Proxy использует `icon.ico` из своего официального репозитория. Иконки появляются и в каталоге, и в задачах/истории. При недоступности сети интерфейс не ломается и сохраняет fallback.

2. **Вкладка «Браузеры».** Добавлены Chrome, Mozilla Firefox, Яндекс Браузер, Opera, Opera GX, Microsoft Edge, Brave, Vivaldi, Tor Browser и LibreWolf. Используются официальные сайты и установщики; Vivaldi и Tor Browser получают версионированную ссылку с официальной страницы. Версии Opera/Opera GX читаются из официальных каталогов выпусков, а версии Chrome/Firefox/Edge/Яндекс Браузера — из публичных источников вендоров.

3. **Обновление.** Чекбокс «Тихое обновление» убран из интерфейса. В каталоге доступны отдельные кнопки «Скачать выбранные» и «Обновить выбранные». Обновление скачивает установщик, затем запускает установку. Известные параметры тихой установки применяются автоматически; для неизвестных флагов установщик запускается интерактивно без угадывания команд. Через контекстное меню строки можно скачать установщик, обновить выбранную программу или открыть официальный сайт.

4. **Описание приложения.** Значок `ⓘ` перед иконкой приложения показывает описание при наведении.

## Ограничения и поведение

- Иконки загружаются при первом показе из сети и кэшируются локально. Если источник недоступен, показывается цветной буквенный значок.
- «Обновить выбранные» запускает официальный установщик для выбранных приложений; для установщиков без проверенного тихого параметра может появиться окно мастера установки.
- Версия Opera/Opera GX извлекается из каталога версионированных выпусков, который публикуется официальным сервером. Если формат каталога изменится, парсер может потребовать обновления; юнит-тесты покрывают его текущую структуру.
- Новые браузеры входят в общий каталог. Автоопределение версии установленного браузера по реестру/EXE зависит от информации, которую он публикует в Windows.

## Проверки

Добавлены тесты каталога браузеров, источников, Opera directory index и парсеров установщиков Tor/Vivaldi. Для проверки на Windows запустить из папки решения:

```powershell
dotnet test .\CoolSnesh.Avalonia.sln -c Release
dotnet build .\CoolSnesh.Avalonia.csproj -c Release
```
