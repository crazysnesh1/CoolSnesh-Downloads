# Примечания к миграции и обновлению функций

Проект переносит загрузчик с WinForms на Avalonia/XAML. Логика каталога, сетевых запросов, определения установленной версии, установок, настроек и безопасного обновления вынесена в отдельные сервисы.

Ключевые блоки изменений перечислены в `../releases/CHANGELOG_FEATURES_RU.md`, а команды сборки и ограничения — в `../../README.md`.

## Перед реальным использованием

1. Собери проект на Windows с установленным .NET 10 SDK и восстанови NuGet-пакеты.
2. Проверь детект установленных версий на своей конфигурации Windows.
3. Сначала испытай загрузку и тихое обновление на тестовой машине.
4. Для Zapret проверь обновление при активной службе `zapret`, а отдельный запуск через BAT ожидаемо будет отклонён, если стратегию нельзя достоверно сохранить.
5. Сохрани старую WinForms-сборку до завершения тестирования.

Сборка и runtime-тесты не выполнялись в среде подготовки, поскольку .NET SDK отсутствует и сеть NuGet недоступна. Не считай исходники проверенной production-сборкой до локального тестирования.
